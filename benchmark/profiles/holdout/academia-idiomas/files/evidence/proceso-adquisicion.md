# Proceso de adquisición de nuevos componentes

Fecha: 22 de septiembre de 2026. Responsable: Íñigo Paredes Lasa.

## op.pl.3.1 Conclusiones del análisis de riesgos

Antes de comprar o contratar un componente se consulta el análisis de riesgos de septiembre de 2026. Si el componente reduce un riesgo identificado, como el robo de portátiles o el phishing, tiene prioridad en el presupuesto.

## op.pl.3.2 Acorde con la arquitectura de seguridad

Cada componente nuevo se compara con la arquitectura de seguridad vigente. No se adquiere nada que exponga la base de datos a internet, abra una conexión no prevista o evite el cortafuegos del proveedor de conectividad.

## op.pl.3.3 Necesidades técnicas, de formación y de financiación

La petición de compra recoge en un mismo formulario las necesidades técnicas, la formación que exigirá a la plantilla y la financiación disponible; la gerencia decide con los tres datos juntos.
